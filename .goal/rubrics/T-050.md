# Rubric — T-050: First real Pathlynks run

Graded by `/outcome-grader` (or the checker, acting as a fresh stateless judge) against the
artifact this task produces: `qa/manifests/t050-*.md` + the run evidence it cites under
`projects/pathlynks/runs/<run_id>/`. No credit for a plausible-sounding manifest — every
criterion below requires a cited file.

## Criteria

1. **Three cases exist, one per kind.** `projects/pathlynks/cases.jsonl` has exactly one
   `kind=best`, one `kind=worst`, one `kind=edge` row, each with real Pathlynks login steps
   (`{{SECRET:...}}` placeholders for real credentials, never a raw value).
2. **A real, visible browser actually ran them.** The run's own log/manifest shows
   `headless: False` for this run (not the project's default `headed=false`), and each case's
   evidence includes at least one screenshot.
3. **A real judge graded each case, not the mock.** All 3 `Verdict.grader_provider` values name
   a real provider (e.g. `anthropic`), never `mock`, unless that case's outcome was genuinely
   `BLOCKED_HITL`/`ERRORED` (in which case `grader_provider="rule"` is correct and expected).
4. **The verdicts are defensible given the evidence**, independently re-read by the grader —
   not just "a Verdict object exists with some result", but a spot-check that BEST's result
   isn't FAIL when the evidence shows a dashboard landing, and WORST's result isn't a clean PASS
   when the evidence shows the login was rejected.
5. **Zero secret hits.** `scripts/check_no_secrets.py` run over the manifest and run directory
   reports 0 leaks — cited output, not a claim.
6. **write_policy=read_only respected.** No evidence of any create/update/delete action against
   the real product beyond submitting the login form itself.

## No-fire

- Exact wording of any error message the product shows (product copy is not this task's concern).
- Coverage of the counsellor role or any screen beyond login (out of scope, see
  `qa/contracts/pathlynks-first-run.md`'s no-fire list).
- Whether the judge's prose is eloquent — only whether its verdict matches its own cited evidence.

## Satisfied when

All 6 criteria are met on cited evidence. A grader marking `satisfied` without quoting the
specific file/line/screenshot that proves each criterion has not actually graded this rubric.
