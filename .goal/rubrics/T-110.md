# Rubric — T-110: Regression proof

Graded by `/outcome-grader` (or the checker, acting as a fresh stateless judge) against
`scripts/regression_proof.py`'s real, cited run output — not a description of what it would do.

## Criteria

1. **A real feature genuinely breaks and genuinely gets un-broken.** The script deliberately
   swaps a working local fixture page for a broken variant (a single, realistic one-value typo —
   `pass123` → `pass124` — not a contrived always-fail switch), runs the suite, then restores the
   original file. Verify: `tests/fixtures/regression_site/login.html` still contains `pass123`
   after a real run (`git diff`/`grep` show no lasting change).
2. **A real headed browser executes both the BEFORE and AFTER runs**, producing real
   `RawResult`/`Verdict` files under `projects/regression-demo/runs/` — cited run directories,
   not simulated output.
3. **Exactly the broken case flips, the unrelated case does not.** The BEFORE run shows both
   cases `PASS`; the AFTER run shows the login case `FAIL` (or, if the judge itself is uncertain,
   `INCONCLUSIVE` — never a false `PASS`) while the homepage case stays `PASS`. No credit for "it
   probably would" — cite the actual verdict JSON files from a real run.
4. **A real, non-mock judge produced the verdicts** (`grader_provider` names a real vendor, e.g.
   `gemini`), matching this project's own standing rule against mock-graded proofs.
5. **No real product was touched.** The proof runs entirely against a local fixture server
   (`127.0.0.1`) — never Pathlynks or any other real product — since deliberately breaking a real
   staging environment was never approved and this system has no write access to one anyway.

## No-fire

- The exact wording of the fixture pages' copy.
- Whether the regression is "realistic" beyond being a plausible one-value typo, not a
  contrived switch.

## Satisfied when

All 5 criteria are met on cited evidence — the real run's console output, the real verdict JSON
files, and the fixture file's confirmed-restored state after the run.
