## Reuse vs build (decision)

**Reuse:** Playwright (Python) + Playwright Test Agents spec format · Playwright MCP for exploration ·
Midscene-style vision assert as fallback · browser-use secrets pattern · WebArena/BrowserGym harness.
**Build:** video/doc → FlowSpec · case expander (taxonomy) · independent grader · coverage loop ·
secrets adapter · benchmark corpus + scoring.
**Avoid:** all AGPL tools, dormant/dead projects, no-export SaaS.
