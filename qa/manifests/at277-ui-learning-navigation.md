## User-visible claim

An operator with an existing case suite can now reach **FlowSpec** and **Sources** from the normal
project Actions card. An existing `NEEDS_EDIT` FlowSpec offers **Add a recording**, and that click
lands on a real Sources page instead of the previous 404. The page registers a server-local video
path through `stages.ingest.register_source` and `ProjectStore.add_source`; it has no UI-only state.
