## This is the first independent live-browser check of these flows this session

The maker ran its own smoke on port 8017. That smoke does not count as validation. This run used
a separate uvicorn on 8019, a separate Playwright Chromium and separate scripts. Every POST was
made by filling and clicking the real form. To test server-side validation, the checker removed
`required`/`type` in the DOM or injected a value after the page's own submit handler. The
maker's report was read only after all findings below were written down.

**Data boundary:** `AUTOTESTER_ROOT` pointed to a scratchpad copy with `projects/pathlynks`,
`projects/erp` and `projects/vidysea-erp` deleted. Nothing under `d:/autoTesting/projects/` was
read or written. The scratch `.env` held only checker canaries. No external host was contacted.
Two fixtures were seeded straight into the scratch store (disclosed in the report): a DRAFT
flowspec and two mock-graded runs.

## What held (PASS, performed and state-asserted)

- **All 17 GET pages and the report page with runs:** 200, **0 console errors from page code**.
  Each console error came from a probe the checker sent on purpose (400/404/500), matched one to one.
- **Onboard server-side validation:** a non-URL or `javascript:` base URL, a domain mismatch or
  empty domains, a `../evil` / `..%2Fevil` / blank slug, and a duplicate slug all return 400. The
  URL is never echoed.
- **XSS:** `<img onerror>` + `<script>` in the project name, a flowspec screen name, a case
  title and a rename did not run on any of 18 pages. The payload renders as text, and the
  downloaded HTML report escapes it.
- **Credential boundary (BR-6 / F-002):** two canary values submitted through onboard (with the
  "Add another credential" row) appear in no raw response and no DOM on 18 pages. A value
  actually present in `.env` is refused without echo in: the project name (alone and embedded),
  a secret description, a crawl-approval note, a flowspec note, a case Value box and a case
  rename. `/env` Save stores the value, shows only `● Set` and never renders it. A real LF is
  refused on `/env` and `/settings/providers`. An undeclared or unknown key is refused.
- **Edit / secrets / crawl approval / cases / flowspec gate / report downloads:** each works as
  claimed and returns a specific refusal for bad input. The crawl-approval and flowspec refusals
  are themed pages (the AT-259/AT-263 raw-JSON class does not reproduce on the review gate).
